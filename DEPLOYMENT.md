# Quick deployment

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel/Netlify.
3. Set the site to use `index.html` as the entry point.
4. Connect `scsnadustech.org` in the hosting provider's Domains section.
5. Before using the Admin dashboard in production, replace the demo login with real authentication and connect file uploads to a backend/storage service.
